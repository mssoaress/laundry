=== LAVANDERIA EMANOEL — REACT ===

1. INSTALAÇÃO
   npm install

2. DESENVOLVIMENTO
   npm run dev
   Abra: http://localhost:5173

3. IMAGEM / LOGO
   Coloque o arquivo logo-nova-lavanderia.png em: public/img/

4. BUILD PARA PRODUÇÃO
   npm run build
   Os arquivos gerados ficam em /dist — suba essa pasta no seu host.

5. HOSPEDAGEM RECOMENDADA (gratuita)
   Firebase Hosting:
     npm install -g firebase-tools
     firebase login
     firebase init hosting  (pasta pública: dist)
     firebase deploy

   Ou Netlify / Vercel: arraste a pasta /dist para o site.

6. USUARIOS
   admin / admin123
   funcionario / funcionario123
   (já cadastrados no Firebase Auth)
